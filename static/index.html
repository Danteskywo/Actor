🛠️ Доступные API эндпоинты:

  • GET /actors/ - Все актеры
  • POST /actors/ - Создать актера (требуется авторизация)
  • GET /actors/{id} - Получить актера по ID
  • PUT /actors/{id} - Обновить актера (требуется авторизация)
  • DELETE /actors/{id} - Удалить актера (требуется авторизация)
  • GET /specials/ - Все специализации
  • POST /specials/ - Создать специализацию (требуется авторизация)
  • DELETE /specials/{id} - Удалить специализацию (требуется авторизация)
  • GET /actors/search/?name=... - Поиск актеров
